HTML y CSS en contexto

HTML organiza el contenido de una página. CSS decide cómo se ve.

1. HTML: estructura

HTML utiliza etiquetas para representar contenido como títulos, párrafos, enlaces o artículos.

<article class="libro" data-id="B-104">
  <h2>Python para análisis de datos</h2>
  <p class="precio descuento">15,99 €</p>
</article>

2. Atributos

  • class: agrupa elementos.
  • id: identifica un elemento único.
  • data-*: guarda información adicional.

3. CSS: selectores

Un selector indica qué elemento queremos seleccionar.

SelectorQué selecciona
.precioTodos los precios
.precio.descuentoUn elemento con ambas clases
[data-id]Elementos con ese atributo

4. El DOM

El navegador interpreta el HTML como un árbol de elementos.

html
└── body
    └── article.libro
        ├── h2
        └── p.precio
